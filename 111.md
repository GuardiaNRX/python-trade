1) Konfiguracja linters (Ruff + Vulture)
pyproject.toml (Ruff)
*** Begin Patch
*** Add File: pyproject.toml
+[tool.ruff]
+target-version = "py311"
+line-length = 100
+extend-exclude = ["backtests/results", "backtests/reports", "data/http_cache", "data/source_snapshots", "data/cache"]
+
+# wykrywaj m.in. nieużywane importy/zmienne i błędy runtime
+select = ["F", "E", "W", "I"]
+ignore = []
+
+[tool.ruff.lint]
+unfixable = ["F401"]  # nie usuwaj automatycznie importów
+
+[tool.ruff.format]
+quote-style = "preserve"
*** End Patch

Biała lista dla Vulture (entry-pointy, wywoływane z CLI/cron)
*** Begin Patch
*** Add File: vulture_whitelist.py
+# Elementy wywoływane pośrednio (cron/CI) albo dynamicznie importowane.
+whitelist = set([
+    "backtests.report_daily:main",
+    "scripts.canary:main",
+    "scripts.smoke_replay:main",
+    "scripts.janitor:main",
+    # API używane przez importy dynamiczne

*** End Patch


Vulture toleruje różne formy whitelist; najprościej przekazać ten plik przez --whitelist vulture_whitelist.py.

2) Kroki CI (GitHub Actions)
.github/workflows/ci.yml
*** Begin Patch
*** Add File: .github/workflows/ci.yml
+name: CI
+on:
+  pull_request:
+  push:
+    branches: [ main ]
+
+jobs:
+  lint-and-test:
+    runs-on: ubuntu-latest
+    strategy:
+      matrix:
+        python-version: [ "3.10", "3.11" ]
+    steps:
+      - uses: actions/checkout@v4
+      - uses: actions/setup-python@v5
+        with:
+          python-version: ${{ matrix.python-version }}
+          cache: "pip"
+      - name: Install deps (minimal)
+        run: |
+          python -m pip install --upgrade pip
+          pip install ruff vulture
+          # minimalne runtime’y do smoke/golden (możesz podmienić na requirements.lock)
+          pip install pyyaml pandas numpy yfinance pandas_market_calendars matplotlib python-dotenv
+          pip install pytest
+      - name: Ruff (lint)
+        run: ruff check .
+      - name: Vulture (dead code)
+        run: vulture . --min-confidence 80 --whitelist vulture_whitelist.py --exclude backtests/results,backtests/reports,data/http_cache,data/source_snapshots,data/cache
+      - name: Golden snapshot test (o ile obecny)
+        run: |
+          if [ -f tests_integration/test_golden_snapshot.py ]; then
+            pytest -q
+          else
+            echo "No golden tests present — skipping."
+          fi
*** End Patch


(Jeśli używasz requirements.lock, w kroku „Install deps” zamień na pip install -r requirements.lock.)
