3) Jak to sprawdzić automatycznie (i podpiąć pod CI)
A) Ruff – nieużywane importy
pip install ruff
ruff --select F401,F822 .    # F401: unused imports; F822: undefined name


Dodaj do CI (np. GitHub Actions) krok ruff z --output-format=github żeby widzieć in-line komentarze.

B) Vulture – martwy kod/funkcje/zmienne (statycznie)
pip install vulture
vulture . --min-confidence 80


Pokaże nieużywane funkcje/klasy/zmienne; krótką listę możesz whitelistować w .vulture-ignore jeśli to są entry-pointy wywoływane z zewnątrz (np. przez CLI).

C) VS Code – Pylance

Po usunięciu importów zrób Pylance: Restart Language Server – ostrzeżenia znikną, jeśli interpreter jest właściwy.
